Why this reads as Tier 1, not just "a small diagram": one utility source, one generator, one ATS, one UPS module, one path end to end — no bus coupler, no second busbar section, no N+1 anywhere. Per the Uptime Institute definition, that single path means planned maintenance on Q2, UPS1, or Q3 takes the IT load down; there's no redundant route around any single device. Compare this to the Tier-appropriate topology built earlier in this conversation (sectionalized B2 with a bus coupler, dual sources via ATS) — that pattern starts to resemble Tier 2/3 thinking, not Tier 1.
Nothing was redrawn by hand. Both renders came from the one sld block above — the app resolves the symbol set from units at render time, the same setting that drives §4.7's metric/imperial conversion. Override it per-document with symbol-set: ansi in frontmatter if a metric project still needs ANSI-style drawings for a US client, without touching a line of the topology.
