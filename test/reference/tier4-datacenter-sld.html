Tier 4 — no shared device, anywhere

Tier 3's STS1 was the one thing Path A and Path B still had in common — a single box that both merges into. Tier 4 removes it: both paths stay fully separate all the way to two independent panels, and it's the load itself that's dual-corded, drawing from both simultaneously with no switching device between them.

Two independent lines land on two independent points of the load — no box for both to pass through, nothing to fault
The tell: count the boxes both lines pass through. In Tier 3, trace either UPS output forward and both eventually enter STS1 — one box, shared. In Tier 4, trace UPSA's output forward and it never touches anything UPSB's output also touches; they land on two separate terminals of the load itself. That's the structural definition of fault tolerant: not "redundant everywhere" in the abstract, but zero shared components between the two paths, full stop — including the switching device.
One more distinction worth being precise about: Tier 3's STS actively selects a source — only one path is "live" to the load at a time, switching on demand. Tier 4 needs both paths simultaneously live, because a switching decision is itself a place a fault-tolerant system can't afford to depend on. That's why the diagram shows two lines into the load rather than one line out of a switch — it's not a drawing simplification, it's the actual difference between "recovers from an unplanned fault instantly" and "recovers from a planned outage cleanly."
Tier 1N capacity. Single path throughout. Any maintenance drops the load.
Tier 2N+1 UPS on one shared bus. Component maintenance is safer; the bus and everything upstream is still a single point.
Tier 3Two independent chains, merged at one STS. Planned maintenance on either full chain: zero impact. STS itself is still one device.
Tier 4Two independent chains, no merge device — dual-corded load. Survives an unplanned fault anywhere in either chain, not just planned work.
