§4.9 — CeTZ Live-Variable Figures

A figure scripted against a live variable

The plot is generated from the same {{Ib}} that drives the voltage-drop calc in the design note's prose (§4.1). Change Ib anywhere upstream and the curve redraws at export — no pasted image to go stale.

engine: cetz-plot source: Q2–MDB1 feeder (C3, 185mm² Cu) live var: Ib
Raw — document source vdrop-mdb1.typ
// Design Note §5.3 — MDB1 feeder voltage drop #import "@preview/cetz-plot:0.1.0": plot, cetz // Ib is the document's live variable (§4.1) — set once, // referenced in prose as {{Ib}} and here in the figure. #let Ib = state-value("Ib") // = 350 A, from Q2 Ir 0.45×In #let R = 0.164 // Ω/km — 185mm² Cu, C3 #let X = 0.075 // Ω/km #let pf = 0.85 #let vdrop(L) = { calc.sqrt(3) * Ib * (L / 1000) * (R * pf + X * calc.sqrt(1 - pf*pf)) } #figure( plot.plot( size: (9, 5.5), x-label: [Cable length $L$ (m)], y-label: [Volt drop (V)], x-tick-step: 25, y-tick-step: 5, { plot.add( domain: (0, 150), vdrop, style: (stroke: rgb("#2B4C7E") + 1.6pt), label: [Ib = ] + str(Ib) + [ A] ) plot.add-hline( 415 * 0.04, // 4% limit, BS 7671 App 4 style: (stroke: (paint: rgb("#B5720F"), dash: "dashed")) ) } ), caption: [Volt drop vs length, C3 (Q2 → MDB1) at Ib = ] + str(Ib) + [ A. Recomputes on export if Ib changes upstream.] )

Same figure block, two states — the amber curve is what the export looks like the moment {{Ib}} is edited upstream, before anyone touches this figure
Nothing here is hand-drawn. Length, resistance, reactance, and power factor come from the C3 cable record; Ib comes from the document's live-variable store (§4.1) — the same value Q2's Ir setting and the prose both reference. Bump Ib from 350A to 420A anywhere in the document — a load addition, a revised diversity factor — and every figure, table, and sentence that cites it updates together at the next export. The amber curve above is what that edit produces; in the real app it's the only curve shown, redrawn in place, not layered like this for comparison.
