Tier 2 — redundant capacity, still one path

Same utility/generator/ATS skeleton as the Tier 1 example. The difference is entirely in the UPS stage: two N+1 modules feed a common output bus, rather than two independent routes to the load.

B1 splits to UPS1 (A) and UPS2 (B) — either alone carries the full load — then rejoins on B2 for a single onward path
Why this is Tier 2, not Tier 1 or Tier 3: the utility/generator/ATS front end is unchanged from the Tier 1 example — still a single source selection, no redundancy there. What's new is UPS1 and UPS2: two 500kVA modules against a load that needs one, so either can fail or go to maintenance without an outage. But their outputs land on the same B2 — there's no second, physically independent route from B2 through Q3 to PDU-1. A fault on Q3, PDU-1, or the B2 busbar itself still takes the load down. That single onward path is what caps this at Tier 2.
Against the Tier 1 example: same node count almost everywhere except one thing — UPS1/UPS2 replace Tier 1's single UPS1, and B1 now has two children instead of one. The diff between the two documents would show exactly that: one busbar gaining a second branch, nothing else in the topology moving. That's the kind of change a word-processor screenshot can't show you at a glance, and a text-described SLD can.
