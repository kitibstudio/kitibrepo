§4.9 — SLD Symbol Library

One source block, two symbol sets

The engineer writes the topology once, in plain text. The symbol set — IEC 60617 or ANSI/IEEE — is resolved automatically from the document's declared unit system (§4.7), and swaps if the template is overridden.
